# Advanced Linux File Compression & Archiving
Today I mastered professional server backup creation and restoration mechanics.
1. 'tar -czvf backup.tar.gz folder/' - Compresses whole directory into highly optimized gzip archive.
2. 'tar -xzvf backup.tar.gz -C output_folder/' - Safely extracts and restores files into a specific target location.
